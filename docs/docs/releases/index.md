# Release notes

Release notes describe what changed in each version and what users need to do when
upgrading. They are the only history of changes; there is no separate changelog. For
upcoming work see the [Roadmap](../contributors/roadmap.md).

The [next release](next.md) page is the working journal for the version currently in
development. It is renamed to `<version>.md` when that version is released.

| --- | --- | --- |
