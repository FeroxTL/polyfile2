# 0.1.0

**Status:** Released

The first working version of Polyfile: a single-user-oriented file manager backed by the
local filesystem, with a web SPA and Django admin for administration.

## Highlights

- Local filesystem storage through `FileSystemBackend` and configurable `FsStorage`.
- A web file manager for browsing, creating, uploading and downloading files.
- Django admin integration for users, storages and file tree records.

## Added

- `FsNode` tree model for files and directories, with path-based API access.
- `FileSystemBackend` as the reference storage backend.
- `FsStorage` configuration, assignable to users.
- SPA file manager:
  - list files and directories;
  - create directories;
  - upload files;
  - download files;
  - delete single files and empty directories;
  - basic file and directory icons.
- Django admin pages for managing users, storages, files and directories.
- Public authentication form for end users, separate from the Django admin login.

## Upgrade notes

This is the initial release. Install it as described in
[Installation & configuration](../operations/installation.md), then create a superuser and
configure an `FsStorage` before uploading files.
